# 磁力指紋改軌：RP 站點統計 → 邊走線 (|B|, Bv) 弧長剖面

WiFi 指紋留在 RP 站點制（逐點時窗統計），磁力指紋改為**沿路網邊走線連續採集**：
選邊（fromNode→toNode，方向明確）、勻速走完、@50Hz 錄原始流，離線用步伐事件做弧長錨定，
每邊每方向建一條「弧長 → (|B|, Bv)」剖面。理由：磁場的資訊在**空間梯度**，不在單點均值——
單點磁力統計（現行 `wifi-fp@1` 的 magMean/magStd）在鋼構大空間鑑別力太低；而沿線序列
比對吃的是剖面形狀，走線一次拿到整條邊的連續樣本，採集效率也遠高於逐點站採。

## 特徵為何是 (|B|, Bv)，不是三軸向量、也不是 (Bh, Bv)

水平向量分量需要 yaw 才能轉進世界座標，而手機的 yaw 來源（rotation vector）本身融合了
磁力計——室內磁異常正是我們要量的訊號，拿被異常污染的 yaw 去分解異常是雞生蛋。
(|B|, Bv) 兩個分量都繞開它：|B| 旋轉不變，Bv 只需重力傾斜補償（TYPE_GRAVITY，不含磁）。
rotvec 仍隨流錄下，但**不入特徵、只做品質守門**（偵測走線中劇烈晃動）。

## 被否決的替代方案

- **磁力跟 WiFi 同用 RP 站點制**：單點統計丟掉梯度資訊；且 702 點逐點站採的磁力時窗
  與走線剖面相比，每點成本高、資訊少。
- **標量合力剖面（只錄 |B|）**：省事，但升級無路——向量可降標量、反之不可，
  現場重走全站的成本遠大於多錄兩個 sensor 流。

## 後果

- 採集單位是**（floor, from→to）含方向**：靠右走使去回程實際是兩條不同的空間線，
  雙向都走、各向獨立剖面、離線不鏡像不合併。全站 walk 邊 57 條＝114 走線為完成度分母；
  gate 邊選收、connector（梯）不收。
- 原始流錄滿 `{t, mag, grav, acc, rotvec}`（`mag-walk@1`），特徵抽取全在離線——
  特徵定義還能改，**採集協議（邊、方向、勻速、手持姿勢）才是不可逆的部分**。
- 弧長錨定壓在步伐事件上，故 acc 與 STEP_DETECTOR 雙保險：硬體步事件缺漏時
  離線從 acc 補抽，避免單一黑盒壞掉＝重走。
- `fp-db` 的 per-RP 磁力欄位（magMean/magStd）將被邊剖面取代；去留在離線建庫案裁定。
